# Portofolio Defsa Yurinda

Situs: https://geosr-lab.github.io/portofolio/ (GitHub Pages dari folder `docs/` di cabang `main`). Bagian dari [GeoSR](https://geosr-lab.github.io/).

- Isi semua karya ada di satu berkas: `konten/karya.json`. Ubah di sana, lalu bangun ulang.
- `python skrip/bangun.py` membangun `docs/` (hanya karya berstatus `publik`).
- `python tests/verifikasi_tata_letak.py` menguji 375, 768, 1280, 1440 px, terang dan gelap.

Huruf Archivo dan Plus Jakarta Sans (SIL OFL 1.1) disimpan lokal, tanpa CDN. Gaya mengikuti `DESIGN.md` repo GeoSR.
